# DARK BET — Android Demo

نسخة تجريبية أولية لتطبيق Android باسم DARK BET. تعرض مباريات كرة قدم حقيقية عند إدخال مفتاح API من football-data.org، وتستخدم معاملات توضيحية ثابتة لا تمثل أسعار مراهنات حقيقية. القسيمة تخصم نقاطاً افتراضية فقط.

## فتح المشروع
1. ثبّت Android Studio على الكمبيوتر.
2. افتح مجلد `DARK_BET` من Android Studio.
3. انتظر مزامنة Gradle وتثبيت Android SDK 35 إذا طُلب ذلك.
4. شغّل التطبيق على محاكي أو هاتف Android مع تفعيل USB debugging.
5. لإنشاء APK: Build > Build Bundle(s) / APK(s) > Build APK(s).

## تفعيل المباريات الحقيقية
1. أنشئ حساباً في https://www.football-data.org/client/register
2. انسخ API token.
3. افتح التطبيق، الصق المفتاح في قسم ربط بيانات المباريات، ثم اضغط حفظ وجلب.
4. التغطية والطلبات تخضع لحدود الخطة المجانية ومزود البيانات.

## ملاحظات أمان
- المفتاح محفوظ محلياً على الجهاز لأغراض النموذج الأولي فقط. لا تستخدم هذا الأسلوب في إصدار عام؛ انقل طلبات API إلى خادم وسيط حتى لا ينكشف المفتاح.
- معاملات 1 / X / 2 في هذه النسخة أمثلة توضيحية وليست احتمالات حقيقية أو توصيات.
- لا يوجد تسجيل مستخدمين أو خادم أو دفع أو سحب أو أموال حقيقية.
- هذا المشروع مخصص لمحاكاة رياضية بالنقاط الافتراضية فقط. لا تحوله إلى خدمة مراهنات حقيقية دون مراجعة قانونية وترخيص صالح في كل سوق مستهدف.

## المتطلبات
- Android Studio حديث
- JDK 17
- Android SDK 35
- اتصال إنترنت لجلب البيانات الحقيقية

## بناء APK تلقائياً عبر GitHub Actions
يوجد ملف workflow في `.github/workflows/build-apk.yml`. بعد رفع المشروع إلى مستودع GitHub، افتح تبويب Actions وشغّل `Build DARK BET APK` (أو ادفع commit إلى main). بعد نجاح البناء، نزّل artifact باسم `DARK-BET-debug-apk` وستجد داخله `app-debug.apk`.
